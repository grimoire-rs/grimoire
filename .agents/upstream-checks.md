# Upstream check ledger

When anyone last looked upstream, per target — not when a fact was
confirmed (that is each claim's own `verified` date in its ledger). Written
only by the `upstream-refresh` skill
([`.claude/skills/upstream-refresh/SKILL.md`](../.claude/skills/upstream-refresh/SKILL.md));
the domain registry is its `references/domains.md`.

- `Last check` advances only when that target's pass completed; a failed
  feed or a silent researcher leaves the row unchanged and says why in `Notes`.
- Dates are `YYYY-MM-DD`; never checked is `—`. `Depth` is `feed | sweep | deep`.
- `Feed cursor` is the last-seen release tag, changelog heading or version —
  never a date or a position.
