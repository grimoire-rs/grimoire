One skill set for every harness

You use Claude Code and Codex on the same machine and want both to run the same review skill, so one agent can check the other's diff with identical instructions. By the end, both agents load the skill from one declaration, and an edit or an update reaches both at once.

before you start grim is installed and both agents have been run at least once, so their home directories exist. Nothing else.

1. Declare the skill once, machine-wide

Global scope is the one that follows you into every repository, which is what a review skill needs. The declaration lands in one file that both agents will be served from.

$ grim --global add ghcr.io/acme/skills/code-review
Kind   Name         Pinned                                           Status
skill  code-review  ghcr.io/acme/skills/code-review@sha256:3b1a…     added

2. Name both agents as targets

Claude Code reads its own skills directory; Codex reads the shared pool. One install writes the same bytes to each place and remembers both as outputs of the one declaration.

$ grim --global install --client claude,codex
Kind   Name         Target                                Status
skill  code-review  ~/.claude/skills/code-review          written
skill  code-review  ~/.agents/skills/code-review          written

3. Check that both agents see it

Ask each agent to list its skills, then run the review from one against a diff the other produced. The result on your screen should be a review that cites the skill by name.

Two things people ask at this point:

what you commit nothing — global scope lives in ~/.grimoire
when you update grim --global update rewrites both copies
